# وصلة — تطبيق أندرويد

نسخة 1.1 لتجميع مقاطع يوتيوب المسموح لك بحفظها وتشغيلها محلياً.

## الموجود في التطبيق

- إدخال رابط يوتيوب وفحص عنوان المقطع.
- استقبال رابط المقطع من زر **مشاركة** في تطبيق يوتيوب.
- تنزيل فيديو بأفضل جودة متاحة أو بحد أعلى 1080p / 720p / 480p / 360p.
- تنزيل صوت MP3 بجودة 192 / 128 / 64 kbps.
- مكتبة محلية للفيديو والصوت، مع ترتيب المقاطع الصوتية بالسهمين.
- مشغل داخلي ينتقل تلقائياً إلى المقطع الصوتي التالي حسب الترتيب.
- تقدم التنزيل في إشعار النظام. تحفظ الملفات في مساحة التطبيق، وتُحذف عند إزالة التطبيق.
- يفحص التطبيق تحديث أداة `yt-dlp` عند أول استخدام ثم مرة يومياً، لمعالجة أخطاء قد تنتج عن تغييرات يوتيوب.

## التثبيت

ثبّت `Wasla-v1.1-debug.apk` على جهاز أندرويد 8 أو أحدث بعد السماح بالتثبيت من المصدر الذي فتحت منه الملف. إذا كانت نسخة 1.0 مثبتة، ثبّت الجديدة فوقها لتحتفظ بمكتبتك. ملف APK هذا نسخة تجريبية موقّعة بمفتاح التطوير، وليست نسخة متجر.

## فتح المشروع وتطويره

افتح مجلد `WaslaAndroid` في Android Studio ثم شغّل `app`. يحتاج البناء إلى Android SDK 35 وJDK 17. يستخدم المشروع مكتبة `youtubedl-android` إصدار 0.18.1 ومشغل Media3.

## حدود النسخة

- لم يُختبر التشغيل على هاتف متصل؛ اكتمل بناء APK بنجاح.
- استخراج روابط يوتيوب يعتمد على `yt-dlp`. يحتاج أول تحديث إلى اتصال إنترنت وقد تبقى بعض المقاطع غير قابلة للتنزيل إذا فرض يوتيوب قيوداً عليها.
- اختيار جودة الفيديو هو حد أعلى؛ عند عدم توفر الجودة المطلوبة، تُختار جودة أدنى متاحة.
- استخدم التنزيل فقط للمحتوى الذي لديك إذن بحفظه ووفق شروط الخدمة المعمول بها.
